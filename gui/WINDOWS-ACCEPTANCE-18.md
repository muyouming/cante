   `LOGPIXELSX` 仍 `96` ✓、`GetDpiForSystem` 仍 `96` ✓、屏幕仍 `1280x800` ✓（§1 末）。

## 1. 为什么改不了缩放（原始输出）

只走 **`DisplayConfig`** 这一条官方路径 ✓（Windows 设置里那个滑块走的就是它 ✓），
**不碰**其它注册表 ✓（安全第一 ✓）。

### 当前状态（读 ✓）

```
GetDpiForSystem = 96
LOGPIXELSX       = 96  （96 = 100%，120 = 125%，144 = 150%）
主屏物理尺寸   = 1280x800
注册表 LogPixels      = （没设过就是空）
注册表 Win8DpiScaling = 0

=== DisplayConfig 活动路径（1 条）===
  sourceId=0  targetId=0  outputTech=4294967295  targetAvailable=1

=== 每个 source 的缩放档位 ===
  sourceId=0  读缩放失败 rc=87（87 = ERROR_INVALID_PARAMETER：这个适配器/输出不支持按 source 调缩放）
```

### 尝试设 125% 之后（读 ✓）

```
=== before SET: record current state ===  saved
=== attempt SET 125% ===
GetDpiForSystem = 96
LOGPIXELSX       = 96
主屏物理尺寸   = 1280x800
```

### 安全核对（**这一步很重要** ✓）

```
LOGPIXELSX now = 96   GetDpiForSystem now = 96
HKCU LogPixels =      HKCU Win8DpiScaling = 0
Screen = 1280x800
```

→ **什么都没被改动** ✓。这台 VM 的显示适配器（`outputTech=4294967295` = 未报告 ✓，
屏幕 `1280x800` ✓）**不支持 DPI 缩放档位** ✓。

**为什么不换条路硬改注册表** ✗：`LogPixels` 那条路要**注销/重启会话**才生效 ✓，
而这是一台**远程**机器（SSH 会话里看不到窗口 ✓，`AGENTS.md` §6 ✓）——
改坏了我就**没法验证"改回来了"** ✗。所以**宁可如实交"改不了"** ✓。

跑法：`gui\scripts\windows\scale\scroll-reach.ps1 -OutDir <目录>` ✓（用的是**安装版** ✓，
`UIA` 取 `BoundingRectangle` ✓，`y` 是**屏幕坐标** ✓）。

  知道了             y=470 h=52 屏外=False 在窗口内=True   ← 能到 ✓

**判据不是"滚了没"** ✓ —— 是"**滚完之后能不能点到**"✓，而且这里**真点了一次** ✓

**按钮高度** ✓：`48` / `52` —— 都 ≥ 44 ✓（这是**物理像素**且当前缩放 = 100% ✓，
