# 第七次真机验收：**装好的应用真的干成一件活**（现在是一行命令）

> 这一轮验的是产品最核心的那句话：**她那边零手工** —— 双击安装 → 打开 → 点一张卡 →
> 真的出一份文件。前六轮验的都是零件（装完目录干不干净、桥能不能跑），没有一轮把
> **装好的那一个 + 包里的桥 + 这台机器上的 pi** 串起来跑成一件活。
>
> 这一轮把它做成了可重复运行的自动化，并连跑三次全绿。原始证据在
> `%TEMP%\cante-accept-harness\`（run-ps1 = 第一次，runB = 第二/三次）。

- 验收机器：Windows 11 Home 25H2 / `10.0.26200` / x64（真机）
- 安装包：Release `gui-v0.2.1` 的 `Cante_0.2.1_x64-setup.exe`（3,553,110 B）
- 运行时：WebView2 `153.0.4234.32`、msedgedriver `153.0.4234.32`、`tauri-driver 2.0.6`、原生 `pi 0.85.1`
- 验收人：跑在那台机器上的 pi（SSH 会话，限制见 §6）
- 分支：`pool3/accept-harness`

---

## 0. 结论先行：**能，而且是自动化的**

```
powershell -NoProfile -ExecutionPolicy Bypass -File gui/scripts/windows/accept-install.ps1 -Version 0.2.1
```

这一条命令做完五件事：下载安装包 → 静默安装并列出安装目录 → 启动应用用 UI Automation
读第一屏 → **在真实 WebView2 里点卡片、选文件、写一句话、生成计划、开始、逐条审批，
真的产出一份 xlsx** → 静默卸载并检查残留。**连跑三次都过**（`exit 0`）：

| 运行 | 取包 | 安装 + 列目录 | 启动 + 读第一屏 | **干成一件活** | 卸载 + 残留 | 合计 |
| --- | --- | --- | --- | --- | --- | --- |
| A（`-Installer <路径>`） | 0.0 s | 2.1 s | 24.0 s | **43.4 s** | 1.2 s | **70.7 s** |
| B（`-Version 0.2.1`，第一遍） | 3.0 s | 1.2 s | 23.6 s | **35.2 s** | 1.1 s | **64.1 s** |
| C（`-Version 0.2.1`，第二遍，同一工作目录） | 1.6 s | 1.1 s | 23.8 s | **34.1 s** | 1.1 s | **61.7 s** |

「干成一件活」这一步内部又分（运行 C 的驱动自报耗时，毫秒）：

```
tauri-driver 就绪=544  打开 WebDriver 会话（启动应用）=420  首页出现=777
点卡片=72  填原生对话框=767  选文件（原生对话框）=1269
写一句话并生成计划=153  确认页 → 开始=89  干活（含审批/提问）=28654
```

干活的 28.7 秒里，驱动替她点了 **9 次「允许这次」**（运行 A/B 各 8 次）——每一次都是一条
真实的工具调用在审批页上等一个答复。

**产出（磁盘上的事实，不是界面说成功）**：

| 运行 | 产出文件 | 大小 | sha256 |
| --- | --- | --- | --- |
| A | `结果_挑出华东区.xlsx` | 5,655 B | `79c41aee…27d3a0fa` |
| C | `结果_挑出华东区.xlsx` | 5,675 B | `8fb6f1d4…7bb7bd16` |

用**应用自带的** `cante-sheets.exe read` 读回来（运行 C）：

```
区域,月份,客户,金额
华东区,3月,甲公司,1200
华东区,4月,丙公司,1500
华东区,5月,戊公司,760
```

原表 6 行里 3 行华东区全在、2 行华南/华北一行都没进来；**原文件 sha256 跑前跑后一致**
（运行 C：`6B06A053…38F98`）→ 原表一个字节都没动。

## 1. 怎么跑（以及它为什么能跑通）

```bash
# 前置（每台机器一次）
cd gui && bun install                              # selenium-webdriver 在这里
cargo install tauri-driver --locked                # WebDriver 服务端
# 原生 pi.exe：npm 装的是 pi.cmd，桥用 CreateProcess 起不来；这台机器上是 ~/.bun/bin/pi.exe

# 验收
powershell -NoProfile -ExecutionPolicy Bypass -File gui/scripts/windows/accept-install.ps1 -Version 0.2.1
# 或者给自己下好的包： -Installer "C:\...\Cante_0.2.1_x64-setup.exe"
```

三个文件（都在 `gui/scripts/windows/`，**没有改任何产品代码**）：

| 文件 | 干什么 |
| --- | --- |
| `accept-install.ps1` | 主流程：取包 / 安装 / 读第一屏 / 驱动干活 + 用自带工具核对产出 / 卸载 + 残留检查，并打印每一步耗时 |
| `accept-drive.mjs` | 用 tauri-driver + selenium 驱动**装好的** `cante-gui.exe`：点卡片 → 选文件 → 写一句话 → 生成计划 → 开始 → 循环把审批页点成「允许这次」 |
| `accept-file-dialog.ps1` | 填应用弹出的**原生**「打开文件」对话框（UI Automation）。这是 `smoke.mjs` 当初停在确认页的原因 |

### 1.1 原生对话框是怎么被填进去的（这一步是本轮的技术关键）

`gui/e2e-windows/smoke.mjs` 明确停在确认页，理由是「下一步是原生文件对话框，WebDriver 驱动不了，
假装点一下就是在测另一个应用」。确实如此 —— 但我们不需要假装：**WebDriver 管 WebView2 里的
界面，UI Automation 从外面管那个原生窗口**，两边各管各的。

实测（`accept-file-dialog.ps1 -Dump`）那条对话框在 UIA 里的形状很固定：

```
#32770 "Open"  —  文件名输入框：AutomationId 1148，class 依次 ComboBoxEx32 / ComboBox / Edit
                  「打开」按钮：AutomationId 1，class Button
```

两个坑，都记在脚本注释里了：控件在 UIA 里报的是 **Pane 而不是 Edit/Button**（所以按
AutomationId + ClassName 找，不按 ControlType）；输入框**不接受** `ValuePattern`（所以退到
Win32 的 `WM_SETTEXT` / `BM_CLICK`，跨进程对标准控件有效）。运行 C 里这两步花了 767 ms + 1269 ms。

## 2. 每一步的实际耗时

见 §0 的表。补两条口径：

- 「启动 + 读第一屏」那 24 秒里，**20 秒是脚本故意等的**（`dump-window-text.ps1 -WaitSeconds 20`，
  等 WebView2 冷启动把字画出来），真正的检查只要几百毫秒。
- 「干成一件活」的 34–43 秒里，**28.7–36.5 秒是模型在干活**（联网的真实服务方），
  界面操作（点卡片、选文件、写一句话、开始）加起来不到 3 秒。

## 4. 她需要做的操作清单

**从她的角度（这就是产品承诺的那条路）**：

1. 双击 `Cante_0.2.1_x64-setup.exe`，跟着装完（Windows 上可能弹 SmartScreen 的「仍要运行」，
   因为安装包没有 Authenticode 签名 —— 这是第六轮就记下的事）。
2. 打开 Cante。第一次会出现向导：**欢迎 → 检查电脑 → 开始使用**（三步，一路点「下一步」）。
3. 首页点一张卡片（本轮用的是「从大表里挑出想要的行」）。
4. 点「选择文件」，在弹出的窗口里选中要处理的表。
5. 用一句话说清要做什么（例：`把华东区的记录挑出来，另存成一张新表`），点「生成计划」。
6. 确认页上核对一下「它打算这样做」，点「开始」。
7. 跑的过程中，它对每一步工具调用都会停下来问；她点**「允许这次」**（本轮 8–9 次）。
8. 看到「做好了」，结果就在原表旁边（`结果_*.xlsx`）。

**脚本替她做、但真实用户要另外交代的事（单独标出来）**：

| 脚本做的事 | 真实用户那边对应什么 | 什么时候不再需要 |
| --- | --- | --- |
| 设 `CANTE_BIN` = 包里那个 `cante-bridge.exe` | **她什么都不用设**：安装包已经把桥装进 `%LOCALAPPDATA%\Cante\`，应用要从那里找它 | **#150**（执行组件随包发）之后，这两个变量应从脚本里删掉 |
| 设 `PI_BIN` = 这台机器上的原生 `pi.exe` | 她的机器上得有能进 `CreateProcess` 的 `pi.exe`（npm 装的 `pi.cmd` 不行） | 同上 |
| 用 `CANTE_ADMIN_CONFIG` 跳过向导直接进首页（干活那一步） | 真实用户要走 §4 第 2 步的向导 | 不适用（只是为了让自动化不重复跑向导） |
| 用 WebDriver + UIA 点按钮、填对话框 | 她自己点、自己选 | 不适用 |

**换句话说**：本轮证明的是「应用 + 包里的桥 + pi 能把活干成」；**「她那边零手工」还差一层** ——
`pi.exe` 现在得由这台机器上的人先装好（`BRIDGE-windows.md` §7.1 的老问题），#150 要解决的就是它。

## 5. 能不能重复跑（第二遍会怎样）

**能，连跑三次都过**（§0 的表）。脚本特意做成幂等的：

- **装之前先卸**：发现 `%LOCALAPPDATA%\Cante\uninstall.exe` 就先静默卸掉，再装新的 ——
  所以第一遍装过、第二遍直接跑也不会「已存在」地失败。
- **每次删应用档案**（`%LOCALAPPDATA%\dev.cante.gui`）：不然向导不会再出现，第三/五步的断言
  就没有意义了。
- **每次清空工作目录**里的上一次产出（除非 `-KeepArtifacts`），所以两次运行不会互相串证据。
- **msedgedriver 缓存在 `gui/e2e-windows/msedgedriver/`**（已 gitignore），第二遍不重新下载。
- **两次运行之间唯一会变的是模型给的文件名**：运行 A/C 叫 `结果_挑出华东区.xlsx`，
  运行 B 叫 `结果_挑出_华东区.xlsx`。脚本不写死文件名，用 `结果_*.xlsx` 找，所以不受影响。
- 每次跑完都**卸载干净**：安装目录、HKCU 卸载登记、开始菜单与桌面快捷方式全没了
  （四次检查结果都是 `False`）；唯一留下的是 `%LOCALAPPDATA%\dev.cante.gui`（WebView2 用户数据，
  预期保留）。

## 6. 我没能验证什么

1. **没有人眼看画面**：这台机器是 SSH 会话。判定依据是 UI Automation 读到的文字、
   WebDriver 的操作结果和**磁盘上的文件**，不是像素。脚本确实存了截图
   （`drive-artifacts/result.png`，237 KB），但**我没有打开它看**。
2. **只跑了一张卡**：`excel.filter`（「从大表里挑出想要的行」，只吃一个文件、产出一张表）。
   其余 31 张卡、尤其是「文件夹」类卡片和微信相关的卡**都没跑**。
3. **自动点「允许这次」不等于真人判断**：真人会看一眼这次调用该不该放行；脚本是无条件放行。
   所以这一轮**没有验**审批语义、危险命令识别、拒绝路径。8–9 次审批全部是「允许」。
4. **联网模型**：用的是本机 pi 自己配置的默认服务方与模型（真实联网调用），
   所以「干成活」28.7–36.5 秒这个数字**依赖网络与那家服务方**，不是离线数字；
   服务方地址没有写进本报告，也没有出现在任何输出里。
5. **首次运行向导只读了第 1 屏**：第 2 步（检查电脑）和第 3 步（开始使用）**没有自动走**——
   干活的第 4 步是用 `CANTE_ADMIN_CONFIG` 跳过向导的（那是产品支持的预置路径）。
   「点完向导第 3 步能进首页」这件事**没有在本轮验**。
6. **原生对话框是程序填的**：`WM_SETTEXT`/`BM_CLICK` 与真人点选不是一回事。真人拖动文件到
   窗口那条路（应用支持 drag-and-drop）**没验**。
7. **卸载残留**只查了五个位置（安装目录、HKCU 卸载登记、开始菜单、桌面、WebView2 档案）；
   注册表其它位置、事件日志、防火墙规则等**没查**。
8. **没有跑完整门禁**（任务明确要求不跑）。改动只涉及 `gui/scripts/windows/**` 与一份文档，
   前端测试不必跑；`secret-scan` 是跑了的。
9. **macOS / Linux**：本轮全是 Windows 结论；`accept-install.ps1` 是 PowerShell，
   另外两个文件（.mjs / .ps1）也只在 Windows 上跑过。

**超时与「确认没有」分开写**：所有外部命令都带超时（脚本里的 `Run-Command` 统一管，
`accept-drive.mjs` 还有 15 分钟的总上限），三次运行**一次都没超时**；
「安装目录没有 .d / 0 字节垃圾」「原件没被动」「卸载没残留」都是**列过、比对过**才写的。
