### 在提示词 / 计划 / 风险里改了什么，为什么

1. **`prompt.ts` 共用的规矩里加了一条「说中文」。** 证据：excel.filter 那一轮的
   最后总结是英文（`Filtered and verified.`），而这句是要给王姐看的。这条写在所有
   卡共用的规矩里，改一处全体生效。

2. **`excel.merge` 的做法第 2 步：列名只差一点点时改成「按意思对齐 + 在结果里点
   名」，不再停下来问。** 理由：计划第 2 步写的是「把所有表的行上下拼在一起」，
   风险也写「会在结果里单独标出来让你改」，只有提示词让助手停下来问，三者互相矛盾；
   真机上助手确实停在 A/B 两个选项上，整轮没产出。改完后同一组脏输入一次跑通：把
   「金额（元）」归到「金额」，去掉 1 条完全重复的行，并在「需要你核对」里点名了
   这对列。

3. **`excel.tidy` 的表头规矩：先判断第一行是不是标题，是标题就用下面一行做列名，
   不把标题并进列名。** 理由：真机上「客户登记表 / 姓名 金额（元）…」两行被并成了
   列名「客户登记表姓名」。改完后第一行是独立的标题行，第二行才是正常列名。

4. **`excel.tidy` 把金额处理写死，并让风险跟它一致。** 同一张脏表两轮跑出两种结果
   （一轮保留「￥1500」文字，一轮去掉符号变成数字），用户没法预期。现在提示词明确
   要求去掉千分位逗号和人民币符号、变成能计算的数字，风险也照着写。

5. **`excel.group` 的两条风险改具体。** 合并单元格：只有最上面一格有值，下面几格
   会归到它名下；隐藏行：可能算进去也可能跳过，要用记录数核对。证据：合并那轮把
   A2:A3 的「销售部」补到了第 3 行；隐藏行一轮算了、一轮跳了，所以风险写成「不一定，
   请核对记录数」。

6. **`excel.diff` 的风险改具体：** 编号一边带空格一边不带时，实际做法是「先去掉两
   头空格再比对，算同一条」。证据：`A02` 和 `A02 ` 没被当成两条不同记录，助手在
   「需要你核对」里主动说明了。

7. **`excel.filter` 的风险改具体：** 那一列两头的空格会先去掉再比对（「华东 」和
   「华东」算同一个）；被隐藏的行会被读出来、也会被挑进去。证据：结果里同时出现了
   带空格的「华东 」行和被隐藏的那条华东行。

8. **`excel.split` 的风险改具体：** 只有名字没有号码的行整格留在原列、另一列留空；
   纯数字手机号写成表格后可能变成数字（Excel 里显示成 1.38E+10）。证据：王五（销售
   部）整格留在「姓名」列；那一轮助手主动说明它手工把两个手机号格改回了文本。

9. **补了两个场景和一个 fixture，专门验证上面两条风险真会发生**：加了
   `excel.merge[列名一致]`（列名对得上时的合并主路径）和 `excel.split[指定分隔符]`；
   fixture 里加了 `销售明细_4月.xlsx`，并把「区域记录表」的隐藏行改成一条华东记录
   （否则「隐藏行会被挑进去」这条风险根本测不到）。

### 没修的问题（需要产品决定或改 Rust，不在本轮允许改的范围内）

1. **`cante-sheets` 读不了 csv，但合并 / 整理 / 挑行 / 拆列四张卡的 accept 里都有
   csv。** 证据：合并那轮 `cante-sheets read` 直接报「这个格式我读不了：…csv」，助手
   改用文本读取并在结果里说明。两条路：给 `read_sheet` 补上 csv，或把 csv 从 accept
   里拿掉。属于 Rust 侧 / 产品决定。

2. **`cante-sheets write` 会把纯数字字符串写成数字。** 证据：拆列那轮助手明说
   「cante-sheets 写入时会把 13800138000 这样的 11 位数字当数值存（Excel 里会显示成
   1.38E+10），所以我在写完之后手工把这两个单元格改回文本」。受影响的会是手机号、
   身份证号、银行卡号。建议写的时候默认按文本，或提供一个「保持文本」的开关。

3. **wechat.table 超时。** 7 次工具调用（Read 1、Bash 6）之后进入很长的思考，421 秒
   内没有 TurnEnd；原始事件在 `work/runs/wechat.table/sweep-events.jsonl`。wechat.ts
   归别的 workstream，本轮没动。

4. **excel.group 的隐藏行行为不确定**（同一份输入一轮算、一轮不算）。本轮只把风险
   写清楚让人去核对；要让它确定，得先由产品决定「隐藏行算不算」，再在提示词里写死。

5. **观察，不算产品 bug：** macOS 上真实桌面不认 HOME 环境变量，文书类助手会写到
   真桌面去。普查用「只收本轮工具参数里出现过的文件」把这一轮的产出收进项目目录再
   核对，报告里也不出现私人路径。产品侧如果在意落盘位置，可以考虑给助手一个明确的
   输出目录。
