# 「发出去的是什么」——所有露出口的口径表（r18）

这份文档回答一件事：**产品里每一处她能看到「谁来处理 / 发了什么」的地方，现在分别是
怎么说的**，逐字列出来，好让下一次改文案的人一眼看出哪里漂了。

红线（AGENTS.md）：**界面必须如实说明谁来处理**。本轮的基准是隐私面板的三句话：

| # | 基准句（`src/simple/copy-privacy-audit.ts` 的 `SENT`） |
| --- | --- |
| ① | `filesStay`：「你的文件一直在这台电脑上，我们不会把你的整个文件夹传出去。」 |
| ② | `textGoes`：「发出去的就是下面这段文字，为了让帮你整理的服务方看懂你要做什么；里面会有你选的文件叫什么、放在哪。」 |
| ③ | `textIsLocal`：「这段文字是在这台电脑上拼出来的，你可以自己看、自己判断。」 |

还有一条并列的事实来源：**「谁来处理」**的名字来自 `store.privacy()` 的 `provider`
（`providerLabel(session())`），面板、确认页、首页摘要都读同一个值。

> 纪律（不能动）：这一节只展示**发出去的那段文字**，绝不读取或展示任何本地文件内容。
> 见 `privacy.ts` / `copy-privacy-audit.ts` 的文件头注释。

## 二、改了什么（本轮，逐字前后）

### A. 确认页补一句「这次内容去哪了」（缺口）
- **问题**：动手前这张纸上写着「它打算这样做」、文件清单、「开始」。她按下「开始」之前的
  最后一屏，**完全没说这次内容会不会发出去、发给谁**——而产品律要求界面如实说明谁来处理。
- **改法**：以面板的三句为基准补一条，文案进 `copy-privacy-audit.ts` 的 `EGRESS`，
  判断进 `privacy.ts` 的 `egressLine()`（只读已有的 `run.online` 与 `privacy().provider`，
  **不新造任何事实**），在 `ConfirmSheet.tsx` 正文最上方渲染。
- 只在本机（`run.online === false`）：
  - 前：「（无）」
  - 后：「这次只在这台电脑上处理，什么都不会发出去。你的文件一直在这台电脑上。」
- 联网、服务方未知：
  - 前：「（无）」
  - 后：「这次要联网：发出去的是这段文字，是在这台电脑上拼出来的。你的文件一直在这台电脑上。」
- 联网、知道服务方：
  - 前：「（无）」
  - 后：「这次要联网：发出去的是这段文字，是在这台电脑上拼出来的。发给帮你整理的服务方：{名字}。你的文件一直在这台电脑上。」

### B. 同一句「联网说明」有两份，措辞不一（`privacy.ts` 那份的「你的」）
- `privacy.ts` 的 `onlineHint` 与 `run.ts` 的 `onlineHint` 是同一句话的两份实现。
  界面上真正显示的是 **`run.ts` 那份**（`ResultCard`）；`privacy.ts` 那份不被界面引用，
  但 `privacy.test.ts` 钉的是它——于是「测试钉的」和「她看到的」差一个「你的」。
- `privacy.ts:58`：
  - 前：「整理时用到了联网，**你的**内容发给了帮你整理的服务方。」
  - 后：「整理时用到了联网，内容发给了帮你整理的服务方。」（与界面上那份逐字一致）

### C. 首页摘要条里「漏了主语」的那一句（`PrivacySummary`）
- 同一个组件里，两种分支一说「**内容**不会离开这台电脑」、一说「联网时发给：{名字}」，
  后者少了主语，和前者的口径不一致（也正是本任务举的「漏了主语」那类例子）。
- `PrivacyPanel.tsx:210`：
  - 前：「联网时发给：{名字}」
  - 后：「联网时内容会发给：{名字}」

## 三、看似不一致、但判定为**不用改**的

| 现象 | 为什么不改 |
| --- | --- |
| 向导（第 8 节）对「内容去哪了」只字未提 | 向导讲的是「怎么开口」+「不动你的文件」，**没有对内容流向做任何声明**，所以它没有说错什么；面板在顶栏一键可达。它的三条承诺由 `copy-first-run.test.ts` 钉死为 3 条，硬塞第 4 条只会让「开始之前先记住三件事」变成四件事。本轮记为**判断性不改**，不是漏看。 |
| 结果卡片说「内容发给了帮你整理的服务方」，**不点服务方的名字** | 卡片只有一次运行的事实（`run.online` 是布尔值，没有名字）；它紧接着就有一个「看看刚才发出去的是什么」的入口，点开就是点名的那一屏。加名字要么改运行记录结构（逻辑），要么让卡片去读全局状态（两张卡可能不同一件）。判为**不用改**。 |
| `onlineLabel` / `onlineHint` 在 `privacy.ts` 与 `run.ts` 各有一份 | B 已把两份**措辞**对齐；完全去重需要动 `run.ts` / `ResultCard.tsx`，两者都不在本任务的改动范围内（`run.ts` 的注释也写明它要保持独立于 `privacy.ts`）。本轮只对齐，不去重。 |
| `PrivacySummary`（首页摘要条）没有被任何地方挂载 | 它当前是死代码，她看不到，所以不改它对用户没有影响；但既然它仍是一份「会说的话」，本轮顺手把里面漏主语的那句补全（见 C）。要不要把它挂回首页属于壳层（`App.tsx`/`Home.tsx`）的改动，不在本轮范围。 |
| 错误出口（第 11 节）不提内容去了哪 | 她的内容已经发出去（或者根本没出去）才走到这里；她要的是「接下来能做什么」，不是重述数据流向。判为**不是露出口**。 |
| 管理员预置说「内容会发出去处理」，面板说「发给你选用的联网服务方：{名字}」 | 一处是「公司允不允许联网」，一处是「这次发给谁」，回答的不是同一个问题，各自都准确。判为**不用改**。 |
| 确认页把文件名和文件夹列出来，而面板说「发出去的这段文字里有文件名和放在哪」 | 两者是同一件事的两种呈现（确认页让她核对选对没有，面板告诉她这些名字会随文字出去），不矛盾。 |
