# 普查用的脏输入

`generate.py` 是唯一的源：它现场生成 .xlsx / .docx / .pdf 和一堆文件，放进
`generated/`（已 gitignore）。为什么不在仓库里直接放这些文件——都是二进制，既占
地方又看不出改了什么，换成脚本才能 diff、才能重复。

```sh
python3 gui/fixtures/sweep/generate.py            # 生成到本目录的 generated/
python3 gui/fixtures/sweep/generate.py 目标目录   # 或指定目录
```

故意做脏的地方，每条都对应一张卡的某个风险：

* 重复行、空单元格、带前导 0 的编号、日期写法多变（`销售明细_1月`、`混乱登记表`）；
* 列名只差一点点（`金额` 对 `金额（元）`）、多表列顺序不同（`销售明细_2月`、`_3月`）；
* 两行表头、空行空列、千分位、货币符号、公式（`混乱登记表`）；
* 合并单元格、隐藏行（`部门明细表`、`区域记录表`）；
* 同一条记录一边带空格（`改动前` / `改动后`）；
* 一列里空格/逗号混用、有名字没号码（`姓名电话`）；
* 文件名日期和修改时间对不上、跨月份、重名、压缩包（`下载文件夹`）；
* 内容相同/不同的文件、嵌套子目录（`重复文件`）；
* 正常 PDF、密码 PDF、没有文字层的扫描 PDF（`材料一`、`加密材料`、`扫描件`）；
* 长文档 .txt / .docx / .md（`年度报告`、`补充说明`）；聊天记录（`聊天记录`）。

只有标准库，PDF 加密用到 `pypdf`（没装就退化为不加密，清单里会标明）。
