# 0.2.1 的全卡普查（#161：覆盖率补到全部卡片 + 夹具缺依赖大声失败 + 每卡两次样本）

基线是上一份报告 `gui/SWEEP-0.2.1.md`。它自己点出了三件事，这份报告把它们落成机制并重跑一遍：

- 验的版本：**已发布的 0.2.1**（核验产出用安装目录里那两个 0.2.1 的 `.exe`）

## 3. 夹具缺依赖：**大声失败**（原始输出）

在**没装 pypdf** 的 WSL 里跑生成器（这就是那台机器上原来的状态）：

```
$ python3 generate.py /tmp/fixture-test
夹具生成缺少依赖，**不生成**（宁可停下，也不要生成一份不一样却看不出来的夹具）：
  - 缺 pypdf：用来生成加密 PDF（pdf.merge 的「加密材料」场景）
      装它：python3 -m pip install pypdf
装完重跑同一条命令即可。
退出码=2
$ ls /tmp/fixture-test
ls: cannot access '/tmp/fixture-test': No such file or directory
```

注意最后一行：**一份夹具都没生成**（连目录都没建）——不是"生成一半、悄悄少一个场景"。

装上之后：

```
$ python3 -m pip install --user --break-system-packages pypdf
Successfully installed pypdf-6.19.0
$ python3 generate.py --check-deps
  pypdf    已装（用来生成加密 PDF（pdf.merge 的「加密材料」场景））
  PIL      已装（用来生成表格照片（vision.table 的截图输入））
依赖齐全。
退出码=0
$ python3 generate.py /tmp/fixture-test
生成到：/tmp/fixture-test      ← 退出码 0，35 份夹具
```

报告里能看出夹具完不完整（`report.md` 自己写的一节）：

```
夹具：共 35 份，**完整 35 份，缺依赖 0 份**。
夹具生成器用到的依赖：pypdf（加密 PDF（pdf.merge 的「加密材料」场景））、PIL（表格照片（vision.table 的截图输入)）。
```

**这个修复立刻改变了结论**：那份「加密材料.pdf」现在**真的加密了**（`/Encrypt` 在里面，1,340 字节；
以前是 864 字节的假加密）。于是 `pdf.merge` 从上一份报告里的"通过"变成**两次都停下问问题**：

```
pdf.merge — 停下问问题（两次样本一致）
- 最后一句：已检查完 3 个文件，**遇到一个必须先确认的问题，暂时没有合并**。
```

也就是说：**上一轮那个"通过"确实是夹具造成的假象**，这一轮换成真夹具后，产品在这张卡上
表现的是"该停下就问"——这才是它真实的样子。

## 6. "停下问问题"9 张，问得对不对

**结论先说：9 张全部问得有依据，其中 7 张是卡片自己写在提示词里要求的，1 张是数据真的有歧义，
1 张是"这活儿现在做不了"。没有一张是"不该问却问了还卡住"。**

| 卡 | 它问/说了什么 | 判断 |
| --- | --- | --- |
| `check.reconcile` | 列了两张表的列名，说"打算按单号对账"，请用户确认再动手 | **该问**：卡片的做法第 1 步原文是"对账靠哪一列必须**先问我确认**，不要自己挑一列就开始" |
| `admin.changes` | "按规矩，动手比对前先请你确认按哪一列认人，我停在这里等你的回复" | **该问**：卡片同样写了"动手以前先问我确认按哪一列认人" |
| `admin.byperson` | 先报三张表的列与人，再问"哪张表一人一行、一人多行的怎么并" | **该问**：卡片写了"动手以前先问我两件事" |
| `invoice.crosscheck` | 指出金额列名不同（台账叫「价税合计」、明细叫「报销金额」），请确认能否按同一含义比 | **该问**：卡片风险里写了"字段叫法不同、拿不准就先问"，这个夹具正是这种情况 |
| `pdf.merge` | 检查完 3 份文件后停下，说有一个必须先确认的问题 | **该问**：夹具里那份真的加密了（§3），卡片的规矩就是"加了密码先停下说清" |
| `pdf.toword[扫描版]` | 用工具验证过"没有文字层"，停下来说明并给选择，没有硬转 | **该问**：这正是卡片设计要挡的那件事 |
| `doc.report[原话]` | 说明这台电脑没有能生成 Word 的工具，先把正文给出来、让用户选 | **该问**：共用规矩里"缺工具先说、给出路" |
| `vision.table` | "这件事现在做不了，我没有硬编表格" | **该说**：这个模型不支持看图（会话里 `support_vision: false`）。**如实说做不到**正是产品律 3 要的；但它意味着**这一张卡在当前模型下无法被真正验证**（见 §8） |
| `excel.filter` | 发现第 3 行区域写的是「华东␣」（末尾多一个空格），问用户算不算华东 | **问得有依据但可以不问**：同一张卡第二次样本的做法更好——**直接挑进去 + 在「需要你核对」里点名这行** |

**`excel.filter` 是这一轮唯一的"波动"样本，值得单独说**：两次用的是同一条提示词、同一份输入，
只差模型自己的判断——第一次停下来问，第二次做完并标注。**一次样本会把前者读成"这张卡卡住了"**。
这就是 #161 要求每卡至少两次样本的理由，现在它有了一个具体例子。

## 7. 顺带修好的一个普查盲区：WSL 里看不见 Windows 的桌面

第一轮全卡跑完时，有 **3 张卡判成"失败"**（`doc.notice[信息齐全]`、`doc.report[信息齐全]`、`research.brief`），
证据是"没有产出"。但助手自己的最后一句写着：

```
文件已写好：`C:\Users\<用户>\Desktop\本周工作汇报-客服系统上线.txt`（桌面，未覆盖任何已有文件）
```

去 Windows 桌面一看，**10 个文件真的在那儿**（通知、请假条、工作汇报、调研报告），
而普查**一份都没收进 run 目录**。原因：普查跑在 WSL 里，`desktop_dirs()` 只看 Linux 侧的家目录，
看不到 `/mnt/c/Users/<用户>/Desktop`；于是 ① 它记成"没有产出"（**假失败**），② 文件真的留在人家桌面上。

修法（`sweep.py::desktop_dirs`）：WSL 里（`/mnt/c/Users` 存在时）把每个用户目录下的
`Desktop` / `桌面` / `OneDrive/Desktop` 也算进"可能的桌面"，交给原有的 `_capture_escaped()`
按"本轮新出现 + 文件名在本轮工具参数里出现过"两条收进 run 目录。

修完重跑这 8 张（doc.* + research.brief，各 2 次）后：

- 3 张"失败"变成 **通过**（产出确实在，只是位置不对）；
- **真实桌面一个文件都没留**（跑完 `ls` 过：只剩原有快捷方式）；
- 全卡结论变成 **0 失败**。

桌面上的那 10 个文件我挪到了 `%TEMP%\cante-acc7\desktop-litter\` 留证，没有留在桌面上。

## 8. 我没能验证什么

**这一节和上面的结论一样重要。**

1. **`vision.table` 没有被真正验证**：这一轮的模型 `support_vision: false`，两次样本都如实说"看不了图"。
   夹具（表格照片）是好的，但**要用一个支持看图的模型跑一遍才算验过**；这属于"环境缺东西"，
   不是"产品不行"，也不是"过了"。
2. **中文发票版式没验**：`invoice.ledger` 的 PDF 字段名是拉丁字母（§2 末尾的说明），
   我们那个标准库 PDF 写入器写不出中文。中文发票的版式差异（一张多票、印章位置、扫描件）没有覆盖。
3. **每张卡只有 2 次样本**：能发现"会变"，但不足以判定"多大概率变"。`excel.filter` 就是这个量级。
4. **两次结论不一致时，没有进一步定位原因**（是提示词里的措辞、还是数据里的空格、还是模型随机）——
   这一轮只做到"标出来"。
5. **`research.brief` 的"通过"只代表它产出了带来源的一页**：内容对不对（财政部文件号、标准数字）
   **我没有逐条核对**，只看了它有来源标注、有"查不到"的诚实说明。
6. **`admin.*` / `check.*` 那几张停下的卡，没有人工"回答"过它的问题**：所以"问完之后能不能做对"
   这一半没验（要有人坐在那儿回答）。
7. **界面**：这一轮全是"真守护进程 + 真模型 + 真文件"，**没有经过界面**（SSH 会话没有交互桌面）。
8. **完整门禁没跑**（任务要求别跑）：`bun test src` / `tsc` / `cargo test` 这次都没跑，交给 CI。
9. **"超时"与"确认没有"分开写**：本轮所有长命令都带超时（下载 600s、四段普查各 3600s、
   `--list` 300s、依赖安装 600s），**一次都没有超时**；§3 里"一份夹具都没生成"是
   **列过目录确认的**；§7 里"桌面一个文件都没留"也是**列过目录确认的**。
