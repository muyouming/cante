The Cante desktop client is built for one audience: **people who do not work in IT** — an office administrator, a finance clerk, a shop owner — on Windows, with WeChat open and Excel that they can copy, paste and sum in.

It is not a chat window and it is not a developer tool. You pick a task, pick the files, say what you want in one sentence, confirm, and read the result. **The interface is Chinese only**, by design: the people it is for do not read English labels, and should never meet the words *model*, *token*, *path* or *permission*.

Three promises decide every trade-off in it:

1. **It finishes the errand.** The entry point is a task, not an empty prompt box.
2. **It cannot wreck your work.** It writes a new file, never over your original, and everything it does can be undone.
3. **You can always tell what happened and what to do next.** Errors say 发生了什么 and 你可以怎么做, and offer a way to hand the detail to an IT colleague.

## Getting started

Install the bundle (see [Installing](#installing)), open it, and the first run walks you through a three-step check of the machine. No account, no API key, no path to type: if the company configured Cante centrally, the wizard skips itself.

Then you see the task cards.

## One card, four steps

| Step | What you do | What the app promises |
| --- | --- | --- |
| 1. Pick | Choose files or a folder through the normal file dialog, or drop them on the window | Nothing is read yet |
| 2. Say | One sentence, prefilled with an example you can edit | Your own words are kept as the task |
| 3. Confirm | Read the plan, the files involved, the estimated effect, **what can go wrong on this task**, and your own track record with it | Nothing has been touched; press 先试跑给我看 to see the plan without running it |
| 4. Result | See the new file, open it or its folder, undo it, or run the task again | Your original files are byte-for-byte unchanged |

While it runs you get the plan as a checklist that fills in step by step, with the elapsed time — not a spinner. Evidence from the [Wharton AI-agent adoption study](https://ai.wharton.upenn.edu/) is blunt that explaining the process is what makes an agent feel reliable and safe, and that admitting known limits raises trust rather than lowering it. So the confirmation sheet names the specific ways *this* task can go wrong, and the result card repeats whatever the run actually flagged for you to check.

## When it stops to ask

Some jobs have a judgement call in the middle: two sheets whose columns are 金额 and 金额（元）, a stray 合计 row among the detail, a folder where two files would end up with the same name. The task prompts tell the assistant to stop and ask instead of choosing for you, and it does.

That question is not a dead end: the result card offers a reply box. Type the answer — 金额（元）就是金额, 填进金额那一列 — and the same job continues where it stopped, with the step list and the clock picking up again. Pressing Enter sends the answer; Shift+Enter keeps a line break. If you would rather not decide, one button says 你看着办, and it finishes the job and tells you what it chose.

## What it can do

The task catalogue is grouped the way the work is, not the way the technology is:

| Group | Tasks |
| --- | --- |
| 表格 | Merge several sheets into one and remove duplicates · pick the rows you want out of a big sheet · split one column into two · group totals and a chart for the monthly report · tidy formats and compare two lists |
| 文件 | Batch rename, file by type, find duplicate files · file a folder's contents into month subfolders · merge, split or convert PDFs |
| 微信 | Turn an exported chat log into a table · write reply drafts you send yourself |
| 文书 | Notices, leave requests, weekly reports — pick a template, fill two or three blanks, adjust the tone · turn long documents into a one-page summary where every point names its source |

### Finding the one you want

The home screen shows the tasks people reach for most; the rest are behind **看看能做什么** on the same screen. That opens a search box you type into the way you would say it out loud — 把表合起来, 去重, 对账, 按月份整理, 微信 — and it answers with tasks, not tool names. Synonym matching is deliberate: 合并 and 汇总 and 拼 are the same intention, and a search that only matched the word on the card would be useless to someone who has never read the card.

Every result states three things before you commit to anything: what it needs from you (files, a folder, or just a sentence), what it will touch, and whether this machine can do it at all. When nothing matches, you get two ways out rather than a dead end: rephrase, or go back and say the whole thing in one sentence.

It is a curated list, not a plugin marketplace, and that is a product decision rather than a limitation of effort: judging whether a third-party capability is safe is not something a non-technical user can do, and asking her to do it means using her files to find out. Everything in the list was written, tested and given its own honest limits by us.

Tasks that need WeChat get their own screen, because that screen has a job: it explains how to export the chat log, and it states the rule in the interface itself.

## It will not damage your work

- **New files, never overwrites.** Every result is saved beside the original with a suffix; the original is untouched. Overwriting is possible only behind a red checkbox on the confirmation sheet.
- **Undo that does not trust the assistant.** Before a run the app snapshots the folders it will touch; after the run it diffs them itself to learn which files appeared. Undo moves those to the trash (recoverable) and restores what was renamed or removed — the safety is built on filesystem facts, not on the agent's word.
- **History.** The last twenty runs list what was processed and what came out, with a one-click undo.
- **A confirmation sheet for anything destructive.** Deletions, overwrites and bulk messages are flagged in red, with the default focus on Cancel.

## Spreadsheets in and out

Excel files are what people actually have, so the app carries a small spreadsheet tool of its own (`cante-sheets`): it reads `.xlsx`, `.xls` and `.csv`, and writes real `.xlsx`. A second one handles PDFs (`cante-pdf`): page counts, merging, splitting, and text extraction that is honest about when it cannot be trusted. Its job is narrow and boring on purpose — keep what the cells meant. Dates stay dates, whole numbers do not sprout a trailing `.0`, a customer number like `00123` keeps its leading zeros, empty cells stay empty, and Chinese sheet names survive the round trip.

At the start of a session the app looks for that tool once; if it finds it, it tells the assistant where it is — in the same place it is told everything else about the job, never guessed. If it is missing, the confirmation sheet says so in the same breath as the plan, with the two honest choices: save the sheet as CSV first, or have a technical colleague install the tool once. What it never does is run for two minutes and then admit, at the end, that it could not write the file.

## Where your data goes

The 隐私 panel answers the question in plain language: what happens on this machine, what needs the network, and who receives it when it does. 只在本机处理 switches the session to local-only and turns off web search; every result card also says whether that run went online.

## WeChat: read and draft, never send

Two red lines, enforced in code and in the interface:

- The app reads a chat log **you exported**. It does not log in to WeChat, does not read your phone, and does not touch an encrypted database.
- It never sends. There is no send button anywhere in the product, drafts are copied by hand, and batch work produces a checklist plus one draft per item. This is a platform and compliance line, not a missing feature.

## When something goes wrong

Every failure is one Chinese pair — 发生了什么, 你可以怎么做 — plus three exits: 重试, 换个方法, and 复制详情 (technical detail for the colleague who helps you). The common cases are mapped to plain language: no network, the file is open in Excel, no permission, the model is not set up yet. A failure leaves your files alone, and says so.

## What it does not do yet

- **Screenshots and photos of tables** are not supported. The client's protocol carries text only, so an image cannot reach the model even if the model could read it, and ordinary office machines have no OCR tool. Shipping a card that made you wait and then fail would be worse than not shipping it. ([#48](https://github.com/muyouming/cante/issues/48) records both routes forward.)
- **Attachments are paths.** You point at a file; nothing is uploaded as bytes. The tray says so rather than pretending otherwise.
- **Scanned PDFs** are not converted silently: the run stops and asks, because the output would be gibberish. Nor are PDFs whose fonts carry no text map — a shape common in Chinese PDFs that came out of a print or export pipeline, where the text is visibly there but the file keeps no way to recover it. Rather than handing you (or the model) a page of noise, the tool says the text is unreliable and the run stops to tell you so. The same rule covers a PDF this machine cannot read at all — you hear about it at the confirmation step, not after waiting.
- **Spreadsheet limits that are real:** a sheet with hundreds of thousands of rows, or one that uses merged cells as headers, may need a hand-checked pass; the confirmation sheet says so before anything starts.
- **Very large tables** (beyond a few hundred thousand rows) and heavily merged spreadsheets may need checking by hand; the confirmation sheet says so up front.
- **The interface is Chinese only**, and the product targets Windows first.

## Installing

Two bundles per release, both unsigned for now:

| Platform | Artefact | Notes |
| --- | --- | --- |
| macOS (Apple silicon) | `Cante_<version>_aarch64.dmg` | Drag to Applications; first launch needs right-click → Open |
| Windows (x86_64) | `Cante_<version>_x64-setup.exe` (per-user) and `.msi` (per-machine) | SmartScreen asks once — 更多信息 → 仍要运行 |

WebView2 is installed by the bundle when the machine does not already have it (Windows 11 ships it). The app is not code-signed yet, so macOS Gatekeeper and Windows SmartScreen both warn on first launch and stop warning afterwards.

## For developers

The client is a Tauri 2 shell around `cante serve`, with a Vite + SolidJS + Tailwind front end. The Rust side owns the daemon process; the front end is plain TypeScript, which is why the task catalogue, the run model and the progress folding all unit-test without a window.

```sh
cd gui
bun install
bun run dev                 # tauri dev against your installed cante
bunx tauri build --bundles app
```

| Where | What |
| --- | --- |
| `gui/CONTRACT.md` | The frozen Rust ↔ front-end contract (commands, events, state transitions) |
| `gui/ROADMAP.md` | The product's persona, product laws, priorities and decision log |
| `gui/src/simple/` | The product surface: home, wizard, runner, result, history, privacy, task catalogue |
| `gui/src-tauri/` | Daemon ownership, the run log and undo, native file dialogs |
| `gui/src-tauri/src/sheets.rs`, `src/bin/cante-sheets.rs` | The spreadsheet tool the app ships (calamine in, rust_xlsxwriter out). `commands.rs` probes for it, `src/simple/capabilities.ts` remembers the answer and writes one line into the prompt envelope, and `src/simple/ConfirmSheet.tsx` states the honest alternative when it is absent. Another tool (PDF, say) copies that shape rather than inventing one |
| `gui/scripts/e2e.sh` | The gate: install, tests, typecheck, web build, fixtures, `cargo test` |
| `gui/scripts/dom-smoke.sh` | Renders the shell in Chrome and reads it back as text (no eyes required) |
| `gui/fixtures/` | A scripted `cante serve` double, so the app runs with no Cante install |

CI runs the same gate on Linux and Windows. That is deliberate: the product targets Windows first, and the dual-platform gate has already caught things this Mac could not — a path spelled `nested\deep.txt` on Windows while everything else used `nested/deep.txt`, and a test that depended on the clock's resolution.
