## Prerequisites

- An API key or subscription from at least one LLM provider (Anthropic, OpenAI, etc.) — or use [offline mode](/local/offline) with no API key

## Installation

Cante is distributed as a single, self-contained binary with no external dependencies — just download and run.

```sh
curl -fsSL https://cante.run/install.sh | bash
```

By default this installs to `~/.cante/bin`. To install somewhere else, set `CANTE_INSTALL_DIR`:

```sh
curl -fsSL https://cante.run/install.sh | CANTE_INSTALL_DIR=/usr/local/bin bash
```

Run the default installer as your normal user, not with `sudo`. A sudoed home-directory install would leave `~/.cante` root-owned and prevent Cante from saving settings and input history, so the installer refuses that combination.

macOS release binaries are Developer ID-signed and notarized, so Gatekeeper accepts them without a manual security bypass.

## Quick examples

### Interactive session

```bash
# Launch the TUI — chat with the agent, approve tool calls, view diffs
cante
```

### Headless one-shot

```bash
# Run a task and exit
cante -p "add error handling to src/main.rs"
```

### Pipe input from stdin

```bash
# Pipe file contents for analysis
cat src/lib.rs | cante -p "review this code for bugs"
```

### Use a different provider

```bash
# Override model and provider
cante --provider openai --model gpt-5.6-sol -p "refactor this function"
```

### Skip tool approvals

```bash
# YOLO mode — auto-approve all tool calls
cante --yolo -p "fix all clippy warnings"
```

### Run as a server

```bash
# Start a long-lived daemon for programmatic integration
cante serve
```

### Update to the latest version

```bash
# Check for a new release and install it
cante update

# Try the development channel for one update
cante update nightly

# Roll back or pin to an exact release
cante update --version v0.2.1
```
